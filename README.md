# 🎮 Unity Junior Programmer Pathway

This repository contains some of my projects and exercises from the **Unity Junior Programmer Pathway**.  
It’s a **work in progress** as I continue through the course.

## 🚧 Status

Currently: **Ongoing**  
I’m steadily working through the modules — this repo will grow as I complete each project.

## 📚 Skills I will learn through this course

- Programming user interfaces (UI design & interactive scripts)
- Application scripting (scene flow, data persistence, APIs, logic structures)
- Code comprehension & clean coding practices
- Debugging (compilation errors, runtime issues, performance)
- Collaboration & communication (feedback cycles, peer review)
- Design process (user testing, iterative design, user-first mindset)
- Project management (planning & managing real-time projects)
- Job preparation (portfolio creation for Unity/game dev roles)
- Programming theory (OOP, inheritance, polymorphism, abstraction, encapsulation)
- Code optimization (efficiency, best practices)
- Version control (maintain projects with Git and Unity workflows)

The course can be found [here](https://learn.unity.com/pathway/junior-programmer?version=6.0).

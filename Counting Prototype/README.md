## Counting Prototype

This project is part of the **Unity Junior Programmer Pathway**.

---

### **Excerise Overview**

In this mission, you expanded your foundational programming skills and built four new projects. Your skills have grown, and the time is right for you to begin developing different concepts for your personal portfolio. You might find that sometimes coming up with an initial idea can be challenging, and you may feel like you don’t know where to start. To help you practice developing your own ideas, you’ll begin this exercise with an existing project as a starting point, and you’ll build a new concept on top of it.

---

### **Core Features / Outcome**

- Use provided counting functionality
- Beads spawn dynamically based on selected difficulty (`Easy`, `Medium`, `Hard`)
- Player can drag and drop beads into color-matching containers
- Correct sorting increases score
- Pause and Resume menu implemented
- Timer (optional, currently disabled) prepared for future use
- Sound when picking up beads
- Background music persists between scenes
- UI screens for **Start**, **Pause**, **Win** and **Game Over** (Game Over currently disabled)
- WebGL build available for browser play

---

### **Bonus / Future Ideas**

- Add visual and audio feedback for correct/incorrect sorting
- Enable the timer for challenge mode
- Add a results screen with performance summary
- Introduce color-blind friendly indicators
